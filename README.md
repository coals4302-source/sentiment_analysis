# sentiment_analysis
Sentiment Analysis through movie reviews

## 1. 프로젝트 개요

- **목적**: 영화 리뷰 텍스트를 POSITIVE / NEGATIVE로 이진 분류  
- **평가 지표**: Matthews Correlation Coefficient (MCC)  
- **데이터**:  
  - 학습: 149,995개 (row_id, text, label)  
  - 테스트: 49,997개 (row_id, text)  
- **실행 환경**: Google Colab / Python 3.10

---

## 2. 데이터 탐색 (EDA)

### 2.1. 클래스 분포

- **NEGATIVE**: 75,170 (50.1%)
- **POSITIVE**: 74,825 (49.9%)
- → 라벨 불균형 없음

### 2.2. 텍스트 길이

- **평균 길이**: 35.2자
- **중앙값**: 27자
- **최대**: 146자
- **라벨별 평균**
  - NEGATIVE: 35.8자
  - POSITIVE: 34.6자

### 2.3. 기타 특이점

- **중복 리뷰**: 3,813개
- **1글자 이하 텍스트 예시**: '굿', '.', '헐' 등

---

## 3. 텍스트 전처리

### 핵심 전략

1. **정규표현식 클리닝**  
   - HTML/특수문자 제거, 이모티콘 보존 ('ㅋ', 'ㅠ', '!!', '♥', '★' 등 토큰 변환)
2. **형태소 분석**  
   - KoNLPy의 Okt 사용, `stem=True`(원형 복원)
3. **품사 필터링**  
   - Noun, Verb, Adjective, Adverb 등 핵심 감성 품사만 유지
4. **불용어 제거**  
   - 감성 정보 없는 일반 단어만 제거

#### 전처리 성능
- 평균 토큰 수: 8.0개 (중앙값 6개, 최댓값 87개)
- 빈 토큰 (학습): 1,798개
- 빈 토큰 (테스트): 589개

---

## 4. 벡터화 및 모델

### 4.1 벡터화

- **Okt 토큰 기반 TF-IDF**: 의미 단위 단어
- **문자 n-gram(char TF-IDF, 2~4자, `char_wb`)**: 비정형/신조어 보완
- 두 벡터를 hstack(수평 결합)하여 사용

### 4.2 분류 모델

- **Logistic Regression** (C 튜닝)
- **LinearSVC**
  
- **교차검증/튜닝**
  - `StratifiedKFold` 5-fold
  - `GridSearchCV`로 하이퍼파라미터 탐색
---

## 5. 모델 성능 및 최종 결론

- **📊최종 선정 모델**  
- **형태소 분석기**  : Okt (stem=True)
- **벡터화**         : 형태소 TF-IDF(1,2) + char TF-IDF(2,5) 결합
- **알고리즘**       : LinearSVC
- **C 파라미터**     : 0.1
- **max_features**   : 70000 (형태소) + 120000 (char)
- **결합 벡터 차원** : 190,000
- **Val MCC        : 0.7485**

## 6. 결론

- 데이터와 라벨 분포가 매우 균등
- 전처리 후에도 평균 8개 토큰 확보, 정보량 충분
- 형/부사 위주로 감성 핵심 보존  
- 이모티콘 등 비정형 신호도 특수 토큰으로 변환, char n-gram으로 유실 최소화  
- 선형 분류기(로지스틱/SVM)에 특화된 피처엔지니어링  
- 실무/경진환경에 적합한 모범적 한국어 텍스트 분류 파이프라인
